# Security policy

Do not put passwords, access tokens, addresses, names, meter identifiers, complete API responses,
or unredacted diagnostics in a public issue.

If the repository host offers private security advisories, use one to report a vulnerability.
Otherwise contact a maintainer privately through a channel they publish on their GitHub profile.
No security email address is asserted by this project.

If a credential was exposed, revoke or change it in Facilioo immediately and remove it from Home
Assistant before collecting further logs.
